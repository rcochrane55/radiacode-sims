# radiacode-sims

This branch simulates a radiacode 103's 1cc CsI(Tl) crystal complete with TiO2 reflectors on 5 of 6 sides, ESR film reflector on the 6th face, 6x6mm SiPM active surface in 7x7mm package joined to a cutout in the ESR film reflector via optical grease. The SiPM is offset from the center of the crystal face by 0.5mm in the +z axis, and the SiPM and ESR reflector are on the +y face. The simulation generates 100,000 optical photons emitted isotropically from each point in a 3d matrix in the crystal and records the number of photons from each point that reach and are detected by the SiPM. By creating a macro that cycles the simulation through a grid of points of arbitrary size, we generate an optical response map of the crystal. Once the simulation completes, we run `merge_outputs.py` to merge the CSV of optical efficienciees with another CSV `map_coords.csv` containing the coordinates of each point in the map to create `optical_response_map.csv`. We then copy the map into the source directory of the gamma simulation under the `main` branch, and then run `optical_weighting.py` with `rootOutput.root` and `optical_response_map.csv` as inputs. I recommend setting this branch up with a separate source and build directory from your main gamma simulation so that you don't overwrite your `rootOutput.root` when running this simulation instead of the gamma transport sim.
