# radiacode-sims

This code simulates a CsI(Tl) gamma scintillator with customizable crystal, reflector, SiPM, and cladding dimensions. The materials are not yet customizable, but they will be in the future. 
There are 2 different source geometry types you can choose, Marinelli or Disk. The Marinelli geometry, if selected, is a 200ml Radiacode marinelli beaker designed for the RC102/103/103G. It most likely will not properly fit an RC110 crystal assembly. If you increase detector size beyond 10x10x10mm you may get geometry overlaps. More preset marinelli geometries will be added going forward, as well as custom Marinelli geometries constructed from primitives. The current Marinelli geometry is imported from the `marinelli_volume.stl` file using CADMesh and thus is not customizable or adjustable.
If you select Disk geometry, you will get a small disk of euxenite-(Y) with customizable dimensions, positioned a variable distance from the center of the scintillator. Source material will be made customizable for both geometry types in the future. I am currently in the middle of refactoring the code to make everything adjustable via macro commands. So far I've just done the geometry, but the material customization will come once the optical map code has also been refactored to be customizable via macro commands.
