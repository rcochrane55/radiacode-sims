# radiacode-sims

This branch simulates a radiacode 103 1cc CsI(Tl) crystal complete with TiO2 reflectors, polyethylene cladding, and silicon slab representing the SiPM, surrounded by a 200ml Marinelli source volume imported by way of a 3d STL file of the 3d printed Marinelli beaker used in the experimental measurements. The source is modeled as a solid volume of KCl, and is made to emit 100 million 1460.8 keV gamma rays. The simulation records the step energy and coordinates of every energy deposition in the crystal and outputs the results as `rootOutput.root`. Then, the optical response map generated by the optical map simulation in the `optical_map` branch is used to interpolate optical response and generate a reconstructed spectrum based on map prediction of detected light for a given deposition's coordinates. With `rootOutput.root` and `optical_response_map.csv` in the build directory, run `optical_weighting.py` to show results and comparison of the simulated K-40 peak to the measured K-40 peak run through the same peak fitting and analysis routine as the simulation.
