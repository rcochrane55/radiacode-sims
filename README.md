# radiacode-sims

test branch contains code for an ideal cubic CsI(Tl) crystal in a Marinelli beaker full of KCl. simulation generates a spectrum from gaussian-smeared energy depositions in the crystal, so essentially this simulation and analysis assumes that the detector electronics are 100% efficient and collect all the light from all scintillation events perfectly. obviously this is not reality, and as a result the simulation overestimates peak area and photopeak efficiency compared to the real detector (radiacode 103 or 102). `show_results.py` shows a strong depth dependence in the probability of a given interaction producing a photopeak event. the inactive shell that is modeled in the simulation in the main branch is one possible method of compensating for the efficiency overestimation, but needs to be tested against a wider range of energies.
